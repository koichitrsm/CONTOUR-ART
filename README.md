# CONTOUR ART

複数の頂上を追加し、地形全体の高さから等高線を再計算するアートアプリです。

## 仕様
1. タップした場所を新しい頂上として追加します。
2. 1か所につき最大10段階の等高線を生成します。画面に収まらない高さの線は生成されません。
3. 線は高さの異なる等高線として地形全体から再計算され、交差・重複を抑えます。
4. 2か所目以降は別の頂上を追加します。既存の頂上との間の鞍部（地形の低い接続部分）を推定し、近似した高さの等高線が自然につながるよう全体を再描画します。
5. 最大5か所まで追加できます。
6. 5か所目の後、全体の線が波打ちながら消えます。

## 操作
- 画面をタップ：頂上を追加
- RESET：最初からやり直し



外部ライブラリ・画像・音声は使用していません。
