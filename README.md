# CONTOUR ART

タップした場所を中心に、10本の黒い同心円を描くシンプルなアートアプリです。

## 使い方
1. 画面の好きな場所をタップすると、等間隔の同心円が10本描かれます。
2. 最大5か所まで続けてタップできます。
3. 5か所目をタップすると、少し間を置いて線が生き物のように波打ちながら消えます。
4. 消えた後は、自動的に新しい作品を描けます。
5. RESETを押すと、いつでも最初からやり直せます。

## GitHub Pagesで公開
1. ZIPを解凍します。
2. `contour-art` フォルダ内の `index.html`、`manifest.webmanifest`、`README.md` をGitHubリポジトリのルートにアップロードします。
3. GitHubの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` と `/ (root)` を指定して **Save** します。

外部ライブラリ・画像・音声は使用していません。
